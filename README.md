# 📄 PDF Merger - Beautiful PDF Merging Tool

A stunning, modern web application for merging multiple PDF files into a single document with an attractive and intuitive user interface.

![PDF Merger Screenshot](https://github.com/user-attachments/assets/1a1b1db8-cd32-409e-b2da-ea137e2e9b02)

## ✨ Features

- **🎨 Beautiful UI**: Modern glassmorphism design with gradient backgrounds
- **📱 Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **🖱️ Drag & Drop**: Simply drag your PDF files onto the upload area
- **📂 File Management**: Reorder files, remove unwanted ones, or clear all
- **⚡ Progress Tracking**: Real-time progress indication during merge process
- **💾 Instant Download**: Download your merged PDF with a single click
- **🔄 Restart Feature**: Easily start over with new files
- **🎯 Smart Validation**: Only accepts PDF files with helpful error messages

## 🛠️ Technology Stack

- **HTML5**: Semantic structure with modern web standards
- **CSS3**: Advanced styling with flexbox, grid, animations, and glassmorphism effects
- **JavaScript (ES6+)**: Modern JavaScript with classes, async/await, and file handling
- **Progressive Enhancement**: Works without external dependencies

## 📋 How to Use

1. **Upload Files**: 
   - Click on the upload area or drag and drop PDF files
   - Select multiple PDF files at once

2. **Manage Files**:
   - Reorder files using the up/down arrows
   - Remove individual files with the trash icon
   - Clear all files with the "Clear All" button

3. **Merge PDFs**:
   - Click the "Merge PDFs" button
   - Watch the progress indicator

4. **Download**:
   - Click "Download Merged PDF" to save your file
   - Use "Merge More Files" to start over

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Local web server (optional, for testing)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yash-bixt/yash-bixt.git
   cd yash-bixt
   ```

2. **Open in browser**:
   - Open `index.html` directly in your browser, or
   - Use a local server:
     ```bash
     python3 -m http.server 8000
     # Then visit http://localhost:8000
     ```

